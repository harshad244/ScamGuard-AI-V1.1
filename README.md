# 🛡️ ScanGuard AI — Full-Stack Scam & Phishing Detection System

A modern, full-stack cybersecurity web application built with **HTML5, CSS3, JavaScript (Frontend in VS Code)** and powered by **Google Apps Script (GAS Serverless Backend)** with **Email OTP verification via GmailApp**, **Google Sheets Database**, and **AI Threat Intelligence**.

---

## 🌟 Key Features

- **🔐 Email OTP Verification**: Real-time 6-digit one-time password delivery straight to user email via `GmailApp.sendEmail()` with a 60-second countdown timer and secure verification.
- **🌐 Phishing URL Scanner**: Multi-factor lexical & heuristic analysis detecting typosquatting, raw IP addresses, URL shorteners, excessive subdomains, and suspicious login keywords.
- **💬 Scam & Phishing Message Detector**: Natural Language Processing (NLP) pattern engine detecting urgency threats, fake banking KYC alerts, lottery prizes, and credential harvesting.
- **📊 Real-Time Analytics Dashboard**: Visual KPI cards and interactive Chart.js graphs (Threat distribution doughnut chart & 14-day scan activity trend).
- **📜 Scan History & Export Reports**: Searchable and filterable history table with instant record inspection, CSV export, and JSON export.
- **👑 Administrator Control Panel**: User management (activate/disable accounts, change roles), system-wide scan audit logs, and AI API configuration.
- **⚡ Zero-Server Deployment**: Serverless backend running on Google Apps Script with auto-provisioned Google Sheets cloud database.
- **🤖 Online AI Integration**: Support for Google Gemini 1.5 Flash AI and Google Safe Browsing threat lists alongside client-side heuristic rules.

## 🚀 Quick Start Guide (VS Code)

### 1. Run the Frontend in VS Code
1. Open the **`ScanGuard`** folder in Visual Studio Code.
2. Install the **Live Server** extension (if not already installed).
3. Right-click on [`index.html`](file:///c:/Users/Harshad%20Teli/Videos/ScanGuard/index.html) and select **"Open with Live Server"** (or simply double-click `index.html` to open in any web browser).

### 2. Connect Your Google Apps Script Backend
1. Open [script.google.com](https://script.google.com/) and create a new project.
2. Copy the code from [`gas/Code.gs`](file:///c:/Users/Harshad%20Teli/Videos/ScanGuard/gas/Code.gs) and paste it into the editor.
3. Click **Deploy > New deployment > Web app** (Set *Execute as: Me*, *Access: Anyone*).
4. Copy the resulting Web App URL and paste it into [`js/api.js`](file:///c:/Users/Harshad%20Teli/Videos/ScanGuard/js/api.js) (or click the **"GAS Endpoint"** badge in the navbar of `index.html` to paste it directly).

*For a detailed walkthrough, see [`deploy_gas_guide.md`](file:///c:/Users/Harshad%20Teli/Videos/ScanGuard/deploy_gas_guide.md).*
